③ 회전(베스트셀러) 점수 — 최대 70
velocity = 이 와인 90일 평균판매 / 전사 1등 와인 판매 (0~1) 회전점수 = velocity × 70
전 거래처 통틀어 잘 나가는 순. 전사 1등이면 velocity=1.0 → 70점.
④ 업태 인기 점수 — 최대 30
segPop = (지정/거래처 업태) 거래처들이 산 이 와인 수량 / 그 업태 1등 수량 (0~1) 업태점수 = segPop × 30
같은 업태(편의점·백화점 등)가 많이 산 와인에 가점. 업태가 비어있으면 0.
⑤ 합계 = 회전(≤70) + 업태(≤30) = 최대 100
베스트셀러업태인기 태그로 표시
⑥ 다양성 + 정렬
점수 내림차순 → (여러 타입이면) 타입별 상한 10개 → 상위 30 → 견적 표시순

⚠ 지금 문제 — 업태 없는 거래처는 상한 70

업태 점수(30)는 거래처의 business_type이 있어야 붙어요. 그런데 전체 거래처의 76%(659/863)가 업태 비어있음. 그런 거래처는 ④가 항상 0 → 점수가 회전 70에 묶여요.

세브도르코리아(업태 비어있음) GH 그라함 식스 그레이프 = 회전 1.0×70 + 업태 0 = 70 ← 실질 만점 GH 그라함 10년 토니 = 회전 0.48×70 + 0 = 34

→ 업태가 없으면 70이 사실상 천장. 이게 "데이터 부재의 페널티"라 아쉬운 지점.
