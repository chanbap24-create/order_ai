현행 점수계산 공식

신규제안 모드 · 2026-07-03 기준 · 코드: app/api/sales/recommend/lib/ (scoring · venueScoring · popularityBlend)

전체 흐름

재고 후보→ 게이트(타입·가격·지역천장)→ 기본점수→ 보정→ 견적학습→ 업장 가산→ 인기 블렌드(선택)→ 정렬·상위30
게이트 통과 못 하면 후보 제외. 점수는 통과한 와인에만 매김. 완벽 매칭 = 100점 (아래 만점 구성).

① 하드 게이트 (통과 못 하면 제외)

  • 재고 — 재고 있는 750ml만(기프트박스·비상품·375ml·매그넘 제외, 가격대별 최소재고).
  • 타입 거래처가 사는 와인타입만 (레드↔화이트 교차 금지).
  • 가격 기준가 ±band 밖이면 제외 (기본 ±20%).
  • 지역천장 산지 계단 매칭 실패 시: 광역(super)=제외 / 국가=같은국가면 타지역 / 제한없음=타지역.

② 기본 점수

// 지역 계단 × 입고빈도 freqMult = (1 − strength) + strength × freqW // strength: 강함0.65·약함0.3·끔0 tierScore = TIER_BASE[t] × freqMult // 같은마을36·인근29·광역23·타지역16 // 취향(품종·향미) soft = (선호품종 ? 0.6:0) + 0.4×향미겹침 softAdd = soft × 8 // 회전(최근 90일 판매) velAdd = velocity × 2 기본 = tierScore + softAdd + velAdd
지역 계단: 같은마을(세부산지) > 인근마을(대지역) > 같은광역 > 타지역. 자주 산 지역일수록 freqW↑.

③ 보정 (순서대로 누적·곱셈)

구분조건식
재주문2회+ 구매·발주주기 경과·대체구매 아님+ 30 × (0.4 + 0.4·강도 + 0.2·지연)
최근제안최근 30일 제안 품목× 0.45

④ 견적학습 (속성 단위 전환, 긍정만 +0~34)

과거 견적을 산지·가격대·타입·품종·향 5속성으로 분해해, 비슷한 새 후보에 "먹혔던 속성"을 가산. 거절은 일반화 안 함(③ 미전환 담당).
속성별 rate=전환수/견적수 · conf=견적수/(견적수+6) sum = Σ mean(rate×conf) · norm = min(5,sum)/5 += norm × 34

⑤ 업장 가산 NEW (업장 유형 적합, +0~20)

거래처 업장 유형(스시·프렌치·이자카야 등 27종, client_venue 태그)에 맞으면 타입·국가·지역 3축 독립 가산. 특정 와인을 콕 집지 않음.
업장 = 타입 8 + 국가 8 + 지역 4 (= venueWeight 20) 타입 : 딱맞음 8 · 무난 4 · 아니면 0 (제외 타입이면 전체 0) 국가 : 선호 나라면 8, 아니면 0 지역 : 선호 지역이면 4, 아니면 0
예 · 이자카야(스파클링·화이트 / 프랑스·독일 / 샴페인·부르고뉴): 샴페인=8+8+4=20 · 부르고뉴화이트=20 · 론 블랑=8+8+0=16 · 이탈리아화이트=8+0+0=8.
배점 근거: 타입·국가가 적합의 핵심(각 8), 정확한 지역은 얹는 보너스(4).

⑥ 인기 블렌드 NEW (선택 · popularity_weight α, 기본 0=끔)

α>0이면 개인화 점수에 전사 베스트셀러(구매폭)를 섞어 전체 재고 유니버스를 재랭킹. 게이트 밖 인기 품목도 끌어올림.
최종 = (1−α)·개인화점수정규화 + α·구매폭백분위 // α≈0.3~0.5 권장(지역확장 '제한없음'과 함께)
백테스트: 게이트 완화 + 이 블렌드로 hit@10이 현행 대비 약 2배. 기본 0이라 켜기 전엔 현행과 동일.

신규제안 만점 구성 (100점)

지역 36 + 견적학습 34 + 업장 20 + 취향 8 + 회전 2 = 100 // 업장 20 = 타입8+국가8+지역4 (지역·견적학습에서 10씩 차출해 신설)
재주문·과거전환은 그 위로 프리미엄 → 100 초과 가능. 인기 블렌드를 켜면 별도 재랭킹(0~100 스케일).

업장 자동학습 (1단계 · 스코어러 미연결)

업장 가산의 타입/국가/지역 점수를 실측 구매 데이터로 자동 산출해 venue_wine_profile 테이블에 저장.
  • 타입 = 절대 비중(그 업장이 실제 많이 사는 타입).
  • 국가·지역 = 초과비중(업장비중 − 전체비중) + 표본 shrinkage + 최소물량 — 편중(프랑스 쏠림)과 희소 노이즈 동시 제거.
  • 갱신: npx tsx scripts/learn-venue-profile.ts --apply
현재는 학습·저장만 하고 라이브 점수엔 반영 안 함(2단계에서 연결 + 백테스트 예정). 라이브는 위 ⑤의 하드코딩 매핑 사용.
