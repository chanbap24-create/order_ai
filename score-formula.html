추천견적 점수 공식

코드 기준: app/api/sales/recommend/lib/scoring.ts · 기본값 = 화면 "점수 가중치(고급)"

전체 흐름

후보 재고→ 게이트 ① 타입→ 게이트 ② 가격(±band)→ 게이트 ③ 지역 천장→ 기본점수→ 보너스/감점→ 견적학습→ 점수 내림차순 정렬
게이트 통과 못 하면 후보에서 제외(continue). 점수는 게이트를 모두 통과한 와인에만 매겨짐.

하드 게이트 (통과 못 하면 제외)

  • 1회성 구매 제외 — 신규제안 모드에서 과거 1회만 산 와인은 제외. 2회+ 구매 = "재주문" 후보로 별도 처리.
  • 타입 신규=거래처가 사는 와인타입만 / 대체=쇼트상품과 같은 타입 / 재주문=면제.
  • 가격 기준가 대비 |가격−기준가|/기준가 > band 면 제외. band 기본 ±20%. 재주문은 면제.
  • 지역 천장 지역 계단 매칭 실패 시: 광역=제외 / 국가=같은 국가면 타지역(3)로 / 제한없음=타지역(3).

① 지역 계단 (tier) — wine_regions 계층

tier의미매칭 기준(거래처 구매 산지와 비교)기본점수
0같은 마을세부산지(sub_region) 일치 — 예: 둘 다 본로마네46
1인근 마을대지역(major_region) 일치 — 예: 둘 다 코트 드 뉘37
2같은 광역광역(super_region) 일치 — 예: 둘 다 부르고뉴29
3타지역천장 설정에 따라 같은 국가/전체21
광역(부르고뉴/보르도)은 코드의 SUPER_REGION_MAP으로 대지역을 묶어 만든 값. 신대륙은 광역이 없어 대지역=광역.

② 기본 점수

// 지역점수 = 계단 기본점수 × 빈도배수 freqW = 해당 계단 매칭산지 구매량 / 그 계단 최다구매량 // 0~1 freqMult= (1 − strength) + strength × freqW tierScore = TIER_BASE[t] × freqMult // 품종·향미 (그 안의 미세 정렬) soft = (선호품종 일치 ? 0.6 : 0) + 0.4 × 향미겹침(0~1) softAdd = soft × softWeight // 회전(최근 90일 평균 판매량) velocity = avg_sales_90d / 최대avg_sales_90d velAdd = velocity × velocityWeight score = tierScore + softAdd + velAdd
strength(입고빈도 반영강도): 강함 0.65 · 약함 0.3 · 끔 0. 대체상품 모드는 0(순수 지역점수).

③ 보너스 / 감점 (순서대로 누적·곱셈)

구분조건식
재주문 2회+ 구매 · 발주주기 경과(overdue≥1) · 대체구매 아님 + reorderBonus × (0.4 + 0.4·강도W + 0.2·min(overdue,3)/3)
최근제안 최근 30일 이미 제안한 품목 score × recentPenalty
과거전환 과거 견적→출고 전환 있음 + min(전환수,3) × convBoost
미전환 2회+ 견적했지만 한 번도 출고 안 됨 score × noconvPenalty
재주문은 "갈아탄(substituted)" 와인이면 제외. 발주주기 전(overdue<1)이면 중복 제안 방지로 제외.

④ 견적학습 (속성 단위 전환, 긍정만 가산)

과거 견적을 산지·가격대·타입·품종·향 5개 속성으로 분해해, 비슷한 새 후보에 "먹혔던 속성"을 가산. 거절은 일반화하지 않음(품목 단위 미전환 감점이 담당).
// 속성별 rate = 전환수/견적수 , conf = 견적수/(견적수 + 6) dim = mean( rate × conf ) // 전환 없으면 0 (감점 아님) sum = dim(산지)+dim(가격대)+dim(타입)+dim(품종)+dim(향) norm = min(5, sum) / 5 // 0~1 += norm × quoteFeedbackWeight

신규제안 만점 구성 (100점)

지역 36 + 견적학습 34 + 업장 20 + 취향 8 + 회전 2 = 100 // 지역·견적학습에서 10씩 차출해 업장 가산(20) 신설
업장 20점은 타입 8 + 나라 4 + 지역 8로 나눠 각 축이 맞을 때 독립 가산(특정 와인을 콕 집지 않음).

예시 계산

스시 거래처 · 같은마을(t=0, 빈도 100%) · 프랑스 샴페인(타입·나라·지역 모두 적합) · 향미겹침 0.5 · 회전 0.5 · 견적학습 norm 0.5 가정
tierScore = 36 × (0.35 + 0.65×1.0) = 36 × 1.0 = 36.0 업장적합 = 타입 8 + 나라 4 + 지역 8 = 20.0 견적학습 = 0.5 × 34 = 17.0 softAdd = (0.6 + 0.4×0.5) × 8 = 0.8 × 8 = 6.4 velAdd = 0.5 × 2 = 1.0 합계 ≈ 80.4점
strength=0.65(강함) 기준. freqMult = (1−0.65) + 0.65×1.0 = 1.0.
